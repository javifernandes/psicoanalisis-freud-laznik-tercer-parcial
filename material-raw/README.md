# Material raw

Esta carpeta conserva las fuentes antes de integrarlas en el libro. No hace falta redactar “lindo”: conviene registrar con fidelidad qué se dijo, en qué clase y a propósito de qué texto.

## Convención para las notas

Cada archivo de notas incluye:

- datos de la clase;
- textos trabajados;
- transcripción o notas casi literales;
- insistencias docentes;
- ejemplos y articulaciones;
- preguntas o dudas pendientes.

Usar marcas simples durante la transcripción:

- `[IMPORTANTE]`: énfasis explícito de la docente.
- `[PARCIAL]`: indicio sobre evaluación o modo de preguntar.
- `[DUDA]`: punto a verificar.
- `[TEXTO]`: referencia bibliográfica o cita para localizar.
- `[ARTICULAR]`: vínculo con otro concepto, texto o módulo.
- `[EJEMPLO]`: caso, escena o ejemplo de clase.

No borrar contradicciones entre clases o fuentes: marcarlas. La resolución editorial se hará después.
