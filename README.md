# Psicoanálisis Freud — tercer parcial

Espacio de trabajo para construir un libro Markdown importable en BookOps sobre el tercer y último parcial de Psicoanálisis Freud, cátedra Laznik (UBA).

Este repositorio continúa el trabajo editorial de `psicoanalisis-freud-laznik-segundo-parcial`. El proyecto `psicoanalisis-freud-laznik-lectura-2do-parcial` se usa sólo como fuente auxiliar: es el dashboard de seguimiento de lecturas de los módulos 3 a 6, no el libro de estudio del segundo parcial.

Alcance inicial:

- Módulo 5: ruptura del principio del placer, pulsión de muerte, complejo de Edipo, complejo de castración y sexualidad femenina.
- Módulo 6: segunda tópica, resistencias estructurales, obstáculos en la cura y tercera teoría de la angustia.

## Carpetas

- `material-raw/`: notas de clase, guías, bibliografía e investigación todavía sin editar.
- `libro/bookops/`: esqueleto del libro final, ordenado para importarlo en BookOps.

## Flujo de trabajo

1. Transcribir cada clase en `material-raw/notas-de-clase/`.
2. Contrastar las transcripciones de las Guías 5 y 6 en `material-raw/guias-de-lectura/` con las notas de clase.
3. Verificar textos y páginas en `material-raw/bibliografia/`.
4. Reunir parciales y preguntas en `material-raw/investigacion-parciales/`.
5. Recién después, convertir el material en capítulos integrados dentro de `libro/bookops/`.

La fuente de verdad pedagógica será: guía/programa de la cátedra + marcas efectivas de clase. Los resúmenes web y parciales anteriores funcionarán sólo como material de contraste y entrenamiento.
