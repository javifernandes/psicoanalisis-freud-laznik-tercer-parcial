## Criterio de uso

Los parciales ajenos no definen el contenido del libro. Se usarán para:

- detectar formas frecuentes de preguntar;
- entrenar articulaciones entre conceptos;
- construir respuestas modelo;
- diseñar simulacros;
- descubrir zonas que necesitan mejor explicación.

No copiar respuestas de sitios de apuntes sin contrastarlas con Freud, las guías y las clases.
